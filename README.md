# Verified Contract Sources

Public, automated archive of verified smart-contract source snapshots.

Each contract is isolated on a branch organized as:

```text
contracts/<environment>/<platform>/<program>-<stable-id>/<chain-id>/<address>
```

Branches contain exact verified source files under `source/` and capture metadata under `.lucidflow/contract.json`. Commits represent archive observations, not deployment transactions, audit conclusions, or security findings.
